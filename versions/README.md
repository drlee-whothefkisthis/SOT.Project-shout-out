# 메인 대회 카드 디자인 버전

## 1번 — 모바일 스와이프 적용 전 (보관용)

- 원본 커밋: `b3c8f971ce586d45f35946e269e5bfd929f3a6f4`
- 보관 파일: `01-before-mobile-carousel/01-Main.css`, `01-before-mobile-carousel/01-Main.js`
- 인기 대회: 4개, 모바일 세로 1열 / PC 2열 2줄. 일·월 타일, 대회명, 코스 정보, 작은 화살표.
- 지난 대회: 날짜와 줄바꿈 대회명 카드, 모바일 2열 / PC 3열.
- 코스 정보 fallback, 검색 자동완성, 카드 선택 후 검색창 스크롤 및 배번호 포커스 포함.
- 사용자가 1번을 요청하면 이 커밋의 루트 CSS/JS jsDelivr 주소를 전달한다. 보관 사본은 변경하지 않는다.
